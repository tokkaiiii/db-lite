# Electron은 서버 내장 없는 얇은 데스크톱 셸

db-lite는 Go 서버 하나가 상시 구동되고 여러 User가 브라우저로 접속하는 공유 서버 구조이며, User/Permission/Audit Log 도메인 모델이 이를 전제로 한다. Electron 패키징을 검토하며 "서버를 Electron 프로세스에 통째로 내장하는 단일 사용자 로컬 앱"과 "기존 서버는 그대로 두고 브라우저 대신 접속하는 얇은 클라이언트" 두 방향을 저울질했다. 목적이 폐쇄망 배포 환경에서 브라우저 주소창/북마크보다 "사내 프로그램" 형태에 익숙한 사용자를 위한 것이므로, 서버는 내장하지 않고 첫 실행 시 입력받아 저장한 서버 주소로 BrowserWindow를 띄우는 최소 셸로 구현하기로 했다. 이렇게 하면 기존 다중 사용자 서버·Permission·Audit Log 모델을 그대로 유지하면서, 조직마다 다른 서버 주소에도 빌드 하나로 대응할 수 있다. 폐쇄망 배포를 전제로 자동 업데이트는 지원하지 않는다.
