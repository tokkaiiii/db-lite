# 쿼리 에디터는 CodeMirror 6(@codemirror/lang-sql) + sql-formatter로 구현

쿼리 실행 화면은 순수 `<textarea>`였다. 여기에 SQL 키워드/테이블명/`별칭.컬럼` 자동완성과 포맷팅을 직접 구현하는 방식과, 이 기능들을 이미 갖춘 에디터 라이브러리를 붙이는 방식을 저울질했다.

`@codemirror/lang-sql`은 스키마(`{테이블: [컬럼...]}`)만 넘겨주면 키워드/테이블/컬럼 자동완성을 기본 제공하고, v6.3.0(2022)부터 `FROM table AS alias` 구문을 직접 파싱해 `alias.` 입력 시 그 테이블의 컬럼을 알아서 제안하는 기능까지 안정적으로 들어있다 — 직접 만들면 SQL 파싱과 별칭 추적을 처음부터 구현해야 했을 부분이다. 포맷팅은 별도로 `sql-formatter`(mysql/postgresql/tsql/plsql 방언 지원)를 붙였다. 두 라이브러리 다 붙이면서 클라이언트 번들이 수백 KB 커졌지만(gzip 기준 약 77KB → 254KB), 자동완성/별칭 추적/포맷팅을 전부 직접 구현하는 비용과 유지보수 부담이 훨씬 크다고 판단해 받아들였다.
